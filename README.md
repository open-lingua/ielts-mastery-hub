## 🧬 MISSION ABSTRACT

**PROJECT DESIGNATION:** IELTS-MH (IELTS Mastery Hub)  
**OBJECTIVE:** EXAM-REALISTIC PRACTICE & AI-POWERED FEEDBACK

IELTS Mastery Hub is a comprehensive simulation system designed for candidates seeking to achieve high band scores in the IELTS Academic and General Training modules. The system provides:

1.  **Writing Simulator:** Dual-pane editor with instant AI-driven evaluation across 4 official IELTS criteria.
2.  **Reading Engine:** Realistic split-screen interface covering 13 official question types with auto-scoring.
3.  **Listening Mainframe:** Audio-driven simulation sections with progressive task difficulty.

## 💉 INJECTION PROTOCOL

**PREREQUISITES:**
*   Node.js v20+ (Runtime Environment)
*   Bun v1.0+ (Package Manager / Runtime)

**INITIALIZATION:**
Clone the classified repository to your local machine.

```bash
git clone https://github.com/LuchoBazz/ielts-mastery-hub.git
cd ielts-mastery-hub
```

**DEPENDENCY INJECTION:**
Install all required modules using Bun.

```bash
# Execute global dependency installation
bun install
```

---

## 🎖️ FIELD OPERATIONS

### **1. Launch the Command Center**

Initiate the development interface. The system will connect to the Supabase mainframe automatically.

```bash
bun dev
```

> **Target Acquired:** The Command Center is now accessible at `http://localhost:5173`.

### **2. Database Synchronization (Optional)**

If you have access to the Supabase CLI, you can pull the latest schema transformations.

```bash
supabase db pull
```

## 📁 CLASSIFIED ARCHITECTURE

The IELTS-MH facility is organized into distinct sectors:

*   **`/src/pages`**: Mission Control. Smart components orchestrating data and layouts.
*   **`/src/components`**: Tactical Units. Domain-specific UI components (Reading, Writing, Listening modules).
*   **`/src/services`**: Intelligence Bureau. Data access layer handling Supabase queries and AI grading requests.
*   **`/src/integrations`**: Secure Communications. Auto-generated SDK clients and database types.
*   **`/supabase`**: Base Camp. Database migrations, seed data, and Edge Function source code.
